# workout-tracker
Benvenuto! Ecco le principali funzionalità e le ultime novità disponibili:
↔️ Riordinamento Schede
Seleziona una scheda e usa le frecce < e > per spostarla a sinistra o a destra nell'elenco.

↕️ Riordinamento Esercizi
Tocca un esercizio per evidenziarlo e usa le frecce ↑ e ↓ a sinistra per cambiarne la posizione.

📋 Copia & Incolla Smart
Duplica un esercizio in qualsiasi scheda dal menu "Incolla in:". I duplicati ricevono automaticamente il suffisso "copia".

⏱️ Timer Reattivo & Suoni
Il timer si aggiorna istantaneamente quando modifichi il recupero. Allarme visivo e sonoro bilanciato a fine tempo.

⚙️ Gestione CSV & Backup
Modifica direttamente il testo, importa o esporta il tuo file CSV toccando l'icona dell'ingranaggio in alto.
